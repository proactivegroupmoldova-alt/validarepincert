# Verificarea certificatelor – AO ProActive Group Moldova

Platforma oficială de verificare a certificatelor emise de AO ProActive Group Moldova.

Fiecare certificat are un cod unic (de exemplu `A-XXXX-XXXX`) și un cod QR care deschide această pagină cu codul completat. Pagina confirmă dacă certificatul este autentic și afișează titularul, tipul certificatului și data emiterii.

Datele titularilor sunt criptate: fără codul tipărit pe certificat nu pot fi citite, nici din pagină, nici din cod.
